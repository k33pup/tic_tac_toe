# Игра "Крестики-нолики"

## Описание
Многопользовательская игра "Крестики-нолики" на C++ с разделением на сервер и клиент. Сервер управляет логикой игры и ведет сессию для двух подключенных игроков. Клиенты отправляют свои ходы на сервер и получают обновления о ходе игры.

## Правила
- Игровое поле состоит из 9 ячеек, пронумерованных от 1 до 9.
- Игроки по очереди выбирают ячейку, чтобы поставить свой символ (X или O).
- Побеждает тот, кто первым составит три символа подряд по горизонтали, вертикали или диагонали.
- При заполнении всех ячеек без победителя засчитывается ничья.

## Запуск
1. **Сервер**: запустите сервер, указав порт для подключения.
   ```bash
   ./server --port <номер_порта>
2. **Клиент**: подключитесь к серверу, указав IP-адрес и порт сервера.
   ```bash
   ./client --connect <IP_адрес>:<номер_порта>
